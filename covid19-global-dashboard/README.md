# COVID-19 Global Dashboard (Power BI)

A Power BI dashboard tracking the global spread and impact of COVID-19 —
cases, tests, recoveries, and deaths, with a geographic map view.

## File

- **`data/Covid19_Dashboard.pbix`** — the full Power BI report (data model + visuals).
  Open with [Power BI Desktop](https://powerbi.microsoft.com/desktop/) to explore interactively.

## Report Pages

| Page | Content |
|---|---|
| **Cover** | Title / landing page. |
| **Map** | Geographic map view of COVID-19 spread. |
| **Cases Report** | Confirmed case trends and breakdowns. |
| **Tests Report** | Testing volume and trends. |
| **Recovered Report** | Recovery trends and breakdowns. |
| **Decomp.tree** | Decomposition tree for drilling into contributing factors. |
| **Deaths Report** | Death trends and breakdowns. |

> Note: only the finished `.pbix` report is included here; the underlying
> raw source data is embedded in the Power BI data model itself.

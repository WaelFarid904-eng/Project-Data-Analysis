# LexEuropa — Legal Case Management Dashboard (Power BI)

A Power BI dashboard built for a legal firm to track cases, lawyer
performance, and office finances.

## File

- **`data/LexEuropa_Dashboard.pbix`** — the full Power BI report (data model + visuals).
  Open with [Power BI Desktop](https://powerbi.microsoft.com/desktop/) to explore interactively.

## Report Pages

| Page | Content |
|---|---|
| **Overview** | High-level summary of the firm's caseload and key metrics. |
| **Case & Lawyer Performance** | Breakdown of cases and performance by lawyer. |
| **Office & Outstanding Balance** | Office-level financials and outstanding balances. |
| **Report** | Detailed report view. |
| **Report2** | Additional detailed report view. |

> Note: the raw case data behind this dashboard is large and sensitive, so
> only the finished `.pbix` report is included here rather than the raw
> source tables.
